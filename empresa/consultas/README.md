# Consultas a un rol

Respuestas escritas de un rol del comité a una pregunta concreta de la persona fundadora, fuera de una reunión (`/consulta <rol> <pregunta>`).

- Nombre: `AAAA-MM-DD-<rol>-<slug>.md`. Lo escribe el rol consultado.
- Las tareas y decisiones que salgan se registran como propuestas y se validan con `/validar`.
- Si una consulta acaba afectando a varias áreas, se convierte en reunión.
