# Reuniones del comité

Una carpeta por reunión: `AAAA-MM-DD-<tema>/` (con sufijo `-2` si hay dos el mismo día). La crea `/reunion`.

| Fichero | Quién lo escribe | Plantilla |
|---|---|---|
| `00-convocatoria.md` | Secretaría | `empresa/plantillas/convocatoria.md` |
| `ronda1-<rol>.md` | cada asistente, a ciegas | `empresa/plantillas/ronda1.md` |
| `ronda2-<rol>.md` | cada asistente (formato completo) | `empresa/plantillas/ronda2.md` |
| `ronda3-<rol>.md` | solo los implicados en bloqueos | `empresa/plantillas/ronda3.md` |
| `acta.md` | direccion-estrategica (la Secretaría solo corrige la forma y pone los IDs con `pba.py registrar`) | `empresa/plantillas/acta.md` |

Las rondas no se editan después de la reunión: son la posición de cada rol en ese momento y explican _por qué_ se decidió algo.
